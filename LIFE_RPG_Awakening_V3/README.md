# LIFE RPG — Awakening V3

- Henrique greeting and anime-style white-haired, green-eyed male avatar.
- Six tappable paths with objective-based percentage completion.
- Dedicated path pages with editable objectives, recommended quests, activity history and milestones.
- Data tab for objectives, quests, backlog and backup management.
- Progress dashboard with completion, XP, actions, time invested, quests claimed, active days and path metrics.
- Local browser storage and PWA support retained.

Open index.html in a modern browser. Host over HTTPS for PWA installation. Export backups regularly; data is stored locally on this device.


### Character portrait
The home profile now uses a detailed generated anime portrait (`henrique-portrait.webp`) with a subtle floating/breathing motion and a soft passing light shimmer. The animation respects the device reduced-motion preference. Keep the image beside `index.html` when hosting the app.
